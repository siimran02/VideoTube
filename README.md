VideoTube is a backend project similar to YouTube, with an additional tweet feature.

I have just completed the user authentication part, where I have implemented many features, such as:

* Registration
* Login
* Logout
* Generating new tokens
* Watch history
* User channel
* Change password
* Get current user
* Change avatar and cover image

For storing the avatar and cover image, I have used Cloudinary, and for the database, I am using MongoDB Atlas.

In the coming days, I will be working on video management. I will implement features such as uploading videos, deleting videos, and managing videos.
