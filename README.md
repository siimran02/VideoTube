
VideoTube is a backend project similar to YouTube, with an additional tweet feature instead of posts.

I have implemented the following features:

1. User (with Authentication): -
    Registration
    Login
    Logout
   Generate new access/refresh tokens
   Watch history
   User channel profile
   Change password
   Get current user
   Change avatar and cover image
2. Video:-
   Upload video
   Delete video
   Update video details
   Get my videos
   Change thumbnail
3. Subscription:-
   Subscribe/unsubscribe to any channel using channel ID
4. Tweet:-
   Create a tweet
   Edit a tweet
   Delete a tweet
5. Comments:-
   Comment on videos
   Comment on tweets
   Edit or delete comments
6. Like:-
   Like videos or tweets
   Get total like count
8. Playlist:-
   Create playlist
   Delete playlist
   Update playlist details
   Add/remove videos from playlist
   Get playlist by ID

For storing the avatar and cover image, I have used Cloudinary, and for the database, I am using MongoDB Atlas.
